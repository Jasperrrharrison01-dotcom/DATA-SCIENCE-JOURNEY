# Lesson 02 — Lists and List Manipulation

## Mini-Project 02: Movie Catalogue Performance Analysis

A Python learning exercise analysing an eight-movie sample catalogue using parallel lists, indexing, aggregation and sorting.

## Concepts applied

- List indexing and alignment with `.index()`
- Aggregation with `len()`, `sum()`, `min()` and `max()`
- Percentage contribution and averages
- Non-mutating sorting with `sorted()` and slicing
- Formatted output with f-strings

## Results

| Metric | Result |
|---|---:|
| Movies | 8 |
| Average duration | 154.9 minutes |
| Longest movie | Titanic (195 minutes) |
| Shortest movie | Joker (122 minutes) |
| Highest-rated movie | The Dark Knight (9.0) |
| Most-watched movie | Avatar (61,000 views) |
| Total views | 359,000 |
| Average views | 44,875 |
| Avatar's view share | 16.99% |
| Three highest ratings | 8.7, 8.8, 9.0 |
| Rating range | 1.20 |

## Analytical takeaway

Popularity and ratings measure different aspects of performance: Avatar leads in views despite having the lowest rating in this sample, while The Dark Knight leads in ratings.
